First & second conditionals: now & the future · điều kiện loại 1, 2: bây giờ & tương lai

Gồm:First ConditionalSecond Conditional

First Conditional nói chuyện CÓ THỂ xảy ra thật: If I have time, I'll help you.
Second Conditional nói chuyện chỉ TƯỞNG TƯỢNG: If I had time, I'd help you.
Cả hai nói về bây giờ hoặc sắp tới; chuyện tưởng tượng dùng V2 trong if clause.

🃏 Tóm tắt

First Conditional

Chuyện CÓ THỂ xảy ra sắp tới và kết quả của nó: If + Present Simple, will + V. Sau if không dùng will.

If + S + V(s), S + will + V

If it rains tomorrow, we'll stay home.

Second Conditional

Tưởng tượng chuyện unreal ở bây giờ, hoặc khó xảy ra: If + V2, would + V. Dạng V2 nhưng nói về hiện tại.

If + S + V2, S + would ('d) + V

If I had a dog, I'd walk it every day.

📈 Dòng thời gian

🧭 Chọn nhanh

❓ Con thấy chuyện này thế nào?

  • •

    Có thể xảy ra thật → First Conditional

    willcanmight

    If it rains tomorrow, we'll play inside.

  • •

    Trái với sự thật bây giờ → Second Conditional

    If I had…If I were…

    If I had wings, I'd fly to school.

  • •

    Khó xảy ra, chỉ mơ ước → Second Conditional

    If I won…If I met…

    If I met a movie star, I'd ask for a photo.

  • •

    Đang khuyên ai đó → Second Conditional

    If I were you

    If I were you, I'd wear a jacket.

📊 Bảng đối chiếu

First ConditionalSecond Conditional
Ý nghĩa có thể xảy ra thậttưởng tượng — trái với thật, hoặc khó xảy ra
If clause if + V(s) — Present Simpleif + V2 / were — dạng Past Simple
Main clause will / can / might + Vwould / could / might + V
Nói về lúc nào sắp tới (hoặc bây giờ)bây giờ hoặc sắp tới — dù dùng V2
Ví dụ If I have time, I'll help you.If I had time, I'd help you.

👯 Có thể xảy ra hay chỉ tưởng tượng?

If I have time, I'll help you.

Chắc tớ có thời gian — tớ sẽ giúp.

If I had time, I'd help you.

Thật ra tớ không có thời gian (tiếc ghê).

If I win the race, I'll get a medal.

Tớ chạy nhanh, có cơ hội thắng thật.

If I won the race, I'd get a medal.

Khó lắm — tớ chỉ mơ thôi.

If we get a dog, I'll walk it every day.

Nhà đang tính nuôi chó thật.

If we had a dog, I'd walk it every day.

Nhà không có chó — chỉ tưởng tượng.

⚠ Lỗi lẫn lộn

✗ If I had a lot of money, I will buy a horse.

✓ If I had a lot of money, I'd buy a horse.

If clause là V2 (tưởng tượng) → main clause dùng would, không dùng will → Second Conditional.

✗ If it rains tomorrow, we would stay home.

✓ If it rains tomorrow, we'll stay home.

If clause là Present Simple (có thể xảy ra) → main clause dùng will → First Conditional.

✗ If I was you, I'll say sorry.

✓ If I were you, I'd say sorry.

Câu khuyên là Second Conditional: If I were you, I'd… — hai clause phải khớp nhau.
