Third Conditional · câu điều kiện loại 3

Tưởng tượng chuyện ĐÃ QUA xảy ra khác đi: If + had V3, would have + V3 — để tiếc, mừng hụt hay trách nhẹ.

📈 Dòng thời gian

🧮 Công thức

+
If + S + had + V3, S + would have + V3 If I had studied, I would have passed the test.
−
If + S + hadn't + V3, S + wouldn't have + V3 If I hadn't overslept, I wouldn't have missed the bus.
?
What would + S + have + V3 + if…? What would you have done if you'd missed the bus?
→ I'd have walked to school.

🧭 Cách dùng

1. Tiếc: chuyện đã qua mà xảy ra khác đi thì kết quả đã khác

  • If I had studied harder, I would have passed the test. — Giá mà tớ học chăm hơn thì đã qua bài kiểm tra. (thật ra tớ trượt)
  • If we had left earlier, we wouldn't have missed the movie. — Đi sớm hơn thì đã không lỡ phim. (thật ra lỡ rồi)

Vế if dùng Past Perfect (had + V3). Nói nhanh: If I'd known…, I'd have… — would have nghe như "would of" nhưng viết là would have. Chỉ muốn nói tiếc thôi: I wish I had studied → wish & if only.

2. Mừng vì thoát, hoặc trách nhẹ

  • If you hadn't helped me, I would have fallen. — Không có cậu giúp thì tớ ngã rồi.
  • If you had told me, I could have helped. — Cậu mà nói với tớ thì tớ đã giúp được rồi.

could have / might have thay would have khi kết quả chưa chắc. Nói một mình, không vế if (You could have fallen!) → Modal + have + V3.

🔑 Dấu hiệu nhận biết

had + V3would havecould have

⚠ Lỗi hay gặp

✗ If I would have known, I would have come.

✓ If I had known, I would have come.

Vế if không dùng would — dùng had + V3.

✗ If I had known, I would came.

✓ If I had known, I would have come.

Vế kết quả là would have + V3 (come → come). Tra V3 ở Irregular verbs.

📎 Được nhắc tới ở

Past Perfect Các thì “Lần đầu, nhất từ trước tới lúc đó (the first time …, the best … ever) kể ở quá khứ → had + V3; nói tới bây giờ thì dùng Present Perfect. had + V3 còn dùng để tưởng tượng chuyện đã qua xảy ra khác đi (If I had known…) → Third Conditional. Kể lại lời nói cũng lùi về had + V3: "I lost it." → he said he had lost it (Tense changes).” if & when Câu điều kiện “Chuyện tưởng tượng (Second Conditional, Third Conditional) chỉ dùng if, không dùng when.” unless Câu điều kiện “Hay đi với First Conditional và Zero Conditional; dùng được cả với Second Conditional, Third Conditional” wish & if only Câu điều kiện “Lùi thì giống vế if của Third Conditional — dạng Past Perfect (had + V3).” Tense changes Câu tường thuật “Loại 1 lùi đúng như luật thường: rains → rained, will → would. Loại 2 và loại 3 đã ở dạng lùi hết cỡ.” Modal + have + V3 Modal verbs “Cùng ý với vế kết quả của Third Conditional khi không nói vế if: (If you hadn't held on,) you could have fallen.” Điều kiện không có thật (loại 2, 3) & câu ước “Chuyện đã qua → vế kết quả là would have + V3 → Third Conditional.”
