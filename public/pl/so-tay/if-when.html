if & when · nếu hay khi

if = NẾU (chưa chắc có xảy ra); when = KHI (chắc chắn sẽ xảy ra, chỉ chờ lúc). Điều lần nào cũng đúng thì if = when.

📏 Quy tắc

1. if — chưa chắc có xảy ra hay không

  • If I see Lan, I'll tell her. — Nếu gặp Lan thì tớ sẽ nói. (chưa chắc gặp)
  • If it snows, we'll build a snowman. — Nếu tuyết rơi thì tụi mình đắp người tuyết.

Chuyện tưởng tượng (Second Conditional, Third Conditional) chỉ dùng if, không dùng when.

2. when — chắc chắn sẽ xảy ra, chỉ chờ tới lúc

  • When I see Lan at school, I'll tell her. — Khi gặp Lan ở trường thì tớ nói. (chắc chắn gặp)
  • When Mom gets home, we'll have dinner. — Khi mẹ về thì cả nhà ăn tối.

Sau when nói về tương lai vẫn dùng Present Simple, không dùng will — giống sau if.

3. Điều lần nào cũng đúng: if và when nghĩa như nhau

  • If you heat ice, it melts. — Đun nóng đá thì đá tan.
  • When you heat ice, it melts. — (nghĩa y như câu trên)

Đây là Zero Conditional.

4. Vế if / when / unless đứng ĐẦU câu → có dấu phẩy; đứng sau → không cần

  • If it rains, we'll stay home. — (vế if đứng đầu → dấu phẩy)
  • We'll stay home if it rains. — (vế if đứng sau → không dấu phẩy)

⚠ Lỗi hay gặp

✗ If I grow up, I'll be a vet.

✓ When I grow up, I'll be a vet.

Lớn lên là chuyện chắc chắn → when.

✗ When I won the lottery, I'd buy a big house.

✓ If I won the lottery, I'd buy a big house.

Chuyện tưởng tượng → if, không dùng when.

✗ If it rains we'll stay home.

✓ If it rains, we'll stay home.

Vế if đứng đầu câu → thêm dấu phẩy.
