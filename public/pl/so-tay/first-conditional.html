First Conditional · câu điều kiện loại 1

Chuyện CÓ THỂ xảy ra sắp tới và kết quả của nó: If + hiện tại đơn, will + V. Sau if không dùng will.

📈 Dòng thời gian

🧮 Công thức

+
If + S + V(s), S + will + V If it rains tomorrow, we'll stay home.
−
If + S + don't/doesn't + V, S + won't + V If you don't hurry, you'll miss the bus.
?
Will + S + V + if + S + V(s)? Will you come if I invite you?
→ Yes, I will. / No, I won't.

🧭 Cách dùng

1. Chuyện có thể xảy ra (bây giờ hoặc sắp tới) và kết quả của nó

  • If it rains tomorrow, we'll play inside. — Mai mà mưa thì tụi mình chơi trong nhà.
  • If I finish my homework, I'll call you. — Làm bài xong là tớ gọi cậu.

Vế if dùng Present Simple dù nói về tương lai; vế kết quả dùng will.

2. Cảnh báo, hứa hẹn, mặc cả

  • If you touch the stove, you'll burn yourself. — Sờ vào bếp là bỏng đấy.
  • If you help me, I'll share my snacks. — Cậu giúp tớ thì tớ chia đồ ăn vặt cho.

Nói "nếu không…" gọn hơn bằng unless: You'll miss the bus unless you hurry.

3. Kết quả chưa chắc: thay will bằng can, may, might — hoặc khuyên, bảo luôn

  • If we leave now, we might catch the bus. — Đi ngay thì có khi còn kịp xe buýt.
  • If you feel sick, you should stay home. — Thấy mệt thì nên ở nhà.
  • If you're tired, go to bed. — Mệt thì đi ngủ đi.

can = có thể làm được; may / might = có lẽ, chưa chắc; should = nên; must = phải.

🔑 Dấu hiệu nhận biết

unlesswillwon'tmight

⚠ Lỗi hay gặp

✗ If it will rain tomorrow, we'll stay home.

✓ If it rains tomorrow, we'll stay home.

Sau if không dùng will, dù nói về tương lai — dùng Present Simple. Sau when, before, after cũng vậy → Time clauses.

✗ If you don't hurry, you miss the bus.

✓ If you don't hurry, you'll miss the bus.

Kết quả ở tương lai → will + V.

✗ If he come, I'll tell him.

✓ If he comes, I'll tell him.

Vế if dùng hiện tại đơn: he, she, it → động từ thêm -s.

📎 Được nhắc tới ở

will Các thì “Sau when, after, before, until, as soon as (Time clauses) — dù nói về tương lai — dùng Present Simple, không dùng will. Sau if cũng vậy → First Conditional.” Second Conditional Câu điều kiện “Cùng một chuyện: thấy có khả năng thì dùng First Conditional, thấy khó thì dùng loại 2 — so sánh ở Điều kiện về bây giờ & tương lai (loại 1, 2).” unless Câu điều kiện “Hay đi với First Conditional và Zero Conditional; dùng được cả với Second Conditional, Third Conditional” Tense changes Câu tường thuật “Loại 1 lùi đúng như luật thường: rains → rained, will → would. Loại 2 và loại 3 đã ở dạng lùi hết cỡ.” Time clauses Nối câu “Vế có when, until… dùng Present Simple; vế còn lại mới dùng will. Sau if cũng vậy → First Conditional.” Điều kiện về bây giờ & tương lai (loại 1, 2) “Vế if là hiện tại đơn (có thể xảy ra) → vế kết quả dùng will → First Conditional.”
